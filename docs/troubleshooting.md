# 问题排查

[项目首页](../README.md) · [文档导航](README.md)

## 日报或工作台打不开

1. 在 Codex 中请求“打开知衡工作台”，使用工具返回的真实地址。默认端口 `3205` 被占用时会选择其他端口。
2. 确认插件已在当前聊天启用并被加载。仅安装插件不会自行启动服务。
3. 在**实际安装目录**运行 `npm run dev`，查看启动错误；自动启动日志位于 `.runtime/workspace.log`。
4. 若设置了 `FINANCE_WEB_AUTOSTART=0`，删除该覆盖或手动启动。

服务停止后，再次调用 `open_financial_workspace` 会重新检查并启动。不要将源码仓库和插件缓存目录当成同一个运行副本；它们各有数据和端口状态。

插件简介的服务主页按当前部署地址填写，运行端口变化时应同步更新。分享日报时，用实际工作台地址加上 `/reports`，并使用 Markdown 的 `[打开日报](实际地址)` 格式；将中文说明放在链接括号之外，避免被自动识别为网址的一部分。

## Python 依赖缺失

在出现故障的运行副本中执行：

```powershell
npm ci --ignore-scripts
npm run setup
```

安装使用本地 uv；确认 `uv --version` 可运行，或设置 `FINANCE_UV` 为其绝对路径。默认环境位于 `.runtime/venvs/finance/`，日志在 `.runtime/workspace.log`；缺失网络、镜像或证书配置时按原始错误修复本机 uv 配置后重试。Ubuntu 报 `libgomp.so.1` 缺失时安装系统包 `libgomp1`。

若使用 `FINANCE_PYTHON`，确认其指向装有 `requirements.txt` 依赖的解释器；安装器只验证这个外部环境，不会自动修改它。仓库已有 `.venv` 不表示新安装的插件副本也有该环境。首次使用需要下载依赖，工具调用若超时，可在后台安装完成后重试；MCP 工具发现不等待 Python 安装。

Windows 若报 DLL 加载失败且提示“文件名或扩展名太长”，请使用更短的安装目录，或通过 `FINANCE_PYTHON` 指定短路径下准备好的环境。部分原生依赖仍受 Windows 路径长度限制。

## MCP 无法启动

确认 Node.js ≥ 22.13。1.1.1 安装器会记录实际 Node 可执行文件、启动脚本和工作目录的绝对路径。检查实际安装副本是否包含 `node_modules`。

若错误路径中原样出现 `${PLUGIN_ROOT}`，或报 Windows 错误 267“目录名称无效”，说明客户端未展开占位符，MCP 尚未启动，工作台自动启动代码也不会执行。在**更新后的源码仓库**运行：

```powershell
npm run repair:mcp
```

该命令只修复知衡：源码指向源码目录，分发配置指向安装缓存，已安装各版本指向各自真实目录。已有的环境变量、其他 MCP 服务器和知衡附加参数会保留。原配置备份在各副本的 `.runtime/mcp-backups/`，不会删除数据或改动认证文件。

只修复指定副本时，Windows 和 Ubuntu 均可执行：

```text
node scripts/configure-mcp.mjs --root "实际插件安装目录"
```

随后重新加载插件或重启 Codex，并新建聊天。验证 `.mcp.json` 中的 `financial.args[0]` 与 `financial.cwd` 都是存在的绝对路径；启动日志应能完成握手并列出 32 个工具。

如果之前用 `codex mcp add financial` 手工注册过同名服务器，正常插件恢复后可用 `codex mcp remove financial` 删除该手工注册项，避免重复加载。使用自定义 Codex 数据目录时，运行安装/修复命令的 `CODEX_HOME` 应与 App 或 CLI 实际使用的目录一致。

## 网页研究或日报复核失败

先检查网页任务中的错误，再确认 `codex login` 已完成。`FINANCE_CODEX_BIN` 指定的命令需要可执行，`FINANCE_CODEX_MODEL` 需要当前账户可用。

研究、日报和持仓识别异步执行；已有任务运行时，新任务会提示等待或取消。失败任务不会被当成成功日报归档。

## 行情、公告或市场数据缺失

- 上游数据服务可能超时、限流或改字段。保留返回的来源、`as_of` 和缺失说明，不让模型补造数据。
- 美股搜索、报价和日线可使用 24 小时内同参数的缓存，来源会标记缓存获取时间；无有效缓存时返回错误。
- SEC 公告需要 `SEC_USER_AGENT`，填写访问者名称与联系邮箱。它不是模型 Key。
- 港股 HKEX 公告与同行披露未接入，缺失提示不是插件安装失败。

需要重装数据依赖时，在对应虚拟环境执行安装命令；不要对其他 Python 环境盲目升级。

## 原盘中回测下载慢或报 UTF-8 错误

“检查 5 分钟线”阶段仍在下载和验收，GPU 不会加速网络取数。已完成且通过验收的缓存会在重试时复用。

BaoStock 超时后继续使用同一连接可能读到上一条响应残留，产生解码错误。现有准备流程会关闭异常连接并重试，失败时保留可用缓存。避免同时启动多轮 BaoStock 采集。原盘中引擎详见[因子研究](factor-lab.md)。
